# my-cli-tool

> C# 学习练习仓库：命令行工具 + 工控通信 Demo。
> 作者：吴冬俊（电工 → 上位机路上）

这个仓库不是成品项目，是我从零学 C# 的练兵场。
每学会一个知识点，就在这里留下一个能跑起来的小工具；能跑起来，比看懂更重要。

## 🎯 这个仓库要练什么

1. C# 基础语法：变量、分支、循环、方法、集合
2. 面向对象：类、属性、继承、接口
3. 常用能力：文件读写、异常处理、JSON、正则、HTTP 请求
4. 工控方向：串口 SerialPort、Modbus RTU、数据解析

## 📁 目录规划

```
my-cli-tool/
├─ 01-basics/          # 基础语法练习（计算器、猜数字等）
├─ 02-oop/             # 面向对象练习（设备类、参数类）
├─ 03-utils/           # 工具类（进制转换、字符串处理）
├─ 04-serial/          # 串口收发 Demo
├─ 05-modbus/          # Modbus RTU 读写 Demo
└─ README.md
```

> 目录会随学习进度逐步创建，没出现的说明还没学到。

## 🧰 环境

- .NET SDK 8（LTS）
- VS Code + C# Dev Kit 插件
- Windows 10/11（串口调试需要实机或虚拟串口工具）

## ▶️ 怎么跑

```bash
# 进入某个练习目录后
dotnet run
```

单个项目单独建，互不干扰；不想污染环境就用 `dotnet new console -n 项目名` 新建。

## 📝 给自己的三条规矩

1. 每天至少推进一个最小可运行的功能，不追求大而全
2. 报错先复制报错信息去查，不从头推导理论
3. 看不懂的先标记，能跑通再回头补原理

仓库内所有通信类代码仅用于本地设备、虚拟串口和授权靶场测试，不用于任何未授权的网络探测。
